# Faithful spatial CBS, PBS, and BCBS baselines

Complete-constraint-tree conflict-based search (CBS), priority-based search (PBS), and
bounded-suboptimal CBS (BCBS, w=1.5) adapted to permanent spatial vertex occupancy, run
on the main 150-scene benchmark with a 60-s per-scene budget and no node limit.

## Layout

```
faithful_baselines_20261105/
  code/
    faithful_spatial_cbs.py       # CBS solver
    faithful_spatial_pbs.py       # PBS solver (Ma et al. AAAI 2019)
    faithful_spatial_ecbs.py      # BCBS(w=1.5) solver (Barer et al. SoCS 2014)
    test_faithful_spatial_cbs.py  # software tests for CBS
    test_faithful_pbs_ecbs.py     # software tests for PBS and BCBS
    stats_faithful_baselines.py   # paired McNemar + bootstrap analysis
  data/
    protocol.json                 # CBS protocol (frozen before run)
    protocol_pbs_bcbs.json        # PBS and BCBS protocol (recorded post hoc)
    formal_cbs/spatial_cbs_raw.csv
    formal_pbs/spatial_pbs_raw.csv
    formal_bcbs/spatial_bcbs_raw.csv
```

## Dependencies

The solvers import `astar`, `generate_instance`, `path_cost`, and `estimate_demand` from
the repo-level `code/run_routing_experiments.py`, and `validate_paths` from
`code/routing_revision_solvers.py`.

## Reproduce

```bash
python faithful_baselines_20261105/code/faithful_spatial_cbs.py  --seeds 50 --deadline 60 --workers 14 --output formal_cbs
python faithful_baselines_20261105/code/faithful_spatial_pbs.py  --seeds 50 --deadline 60 --workers 14 --output formal_pbs
python faithful_baselines_20261105/code/faithful_spatial_ecbs.py --seeds 50 --deadline 60 --workers 14 --output formal_bcbs
python faithful_baselines_20261105/code/stats_faithful_baselines.py
```

The raw CSVs in `data/` contain only summary rows (density, seed, method, success, cost,
runtime, expanded, status). Full path coordinates are not included to keep the archive
small; they can be regenerated by the solvers.

## Key results

| Solver | Low | Medium | High |
|---|---|---|---|
| CBS | 39/50 | 5/50 | 0/50 |
| PBS | 49/50 | 38/50 | 19/50 |
| BCBS(1.5) | 48/50 | 27/50 | 5/50 |
| MSPP-random | 48/50 | 33/50 | 6/50 |
| Proposed | 48/50 | 36/50 | 9/50 |

At high density, PBS completed 19/50 scenes versus 9/50 for the proposed method
(Holm-adjusted exact McNemar p = 0.006). This is an adverse result for the
congestion-guided repair and is reported as such in Supplementary Note S1.

All 230 returned solutions (44 CBS, 106 PBS, 80 BCBS) passed independent
`validate_paths` checks. No PBS solution was cheaper than the CBS optimum on any scene
solved by both (0/44), and BCBS cost stayed within [1.0, 1.5] times the CBS optimum
(0/43 violations).
